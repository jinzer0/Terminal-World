# Terminal-World 분석 산출물 범위 결정

결정일: 2026-10-25

대학 소프트웨어공학 과제의 분석 방법으로 OOA/D를 채택하고 다음 8개 산출물을 작성하기로 했다.

| 산출물 | 내용 |
|---|---|
| 문제 정의 | 개발 배경, 해결할 문제, 시스템 목표 |
| 시스템 범위 | 시스템 경계, 포함·제외 기능 |
| 기능 요구사항 명세 | 제공 기능과 기대 동작 |
| 비기능 요구사항 | 품질 속성과 확인 기준 |
| 제약조건 | 실행 환경과 준수 사항 |
| 유스케이스 모델 | 액터, 시스템 경계, 유스케이스와 관계 |
| 유스케이스 상세 명세 | 사전·사후조건, 기본·대안·예외 흐름 |
| 도메인 모델 | 문제 영역의 개념, 속성, 관계와 다중성 |

도메인 모델은 문제 영역의 개념을 표현한다. 기존 프로토타입은 화면과 개념을 파악하는 참고 자료로 사용한다.

후속 기능·정책 결정은 [10월 26~27일 기록](2026-10-26.md), 최종 변경은 [10월 27~28일 기록](2026-10-27.md)에 정리했다. 산출물별 위치는 [산출물 안내](analysis-deliverables.md)를 따른다.
