# 2026-11-02 요구사항 개정 결정

## 1. 확정 범위

- 기존 SSH 기반 커뮤니티와 개인 공간·집중·채팅·게시판은 유지한다.
- CLI와 MCP에서 같은 커뮤니티 업무를 이용한다. 데이터·인증·권한·보존 규칙을 공유하고, AI의 쓰기는 사용자가 허용한 범위로 제한한다.
- 중·소규모 및 신생·트렌디한 오픈소스의 공개 이슈를 언어·분야·관심사로 탐색한다. AI는 요약·필요한 배경지식·추천 이유를 근거와 함께 제공한다. 선택 이후 기여는 GitHub 원문에서 진행한다.
- 기존 MCP·Skills 게시판을 유지한다. MCP 게시판은 게시글 분류이며 새 MCP 서버 연동과 구분한다.
- 앞서 채택한 프로젝트·공모전·해커톤 모집 게시판을 유지한다. 조건별 탐색·작성자 관리·마감·본인 관심 글 저장을 제공하고 지원은 글에 적힌 연락 방법으로 연결한다.

## 2. 보류·제외

- 원클릭 수정 준비와 기존 페어 프로그래밍·프로필 외부 활동 카드는 보류한다.
- 이슈 작업실·막힌 부분 공유·도움 요청·공동 해결·PR 후속 관리를 추가하지 않는다.
- 별도 워크플로 공유소·프로젝트 발표 게시판·학교 커뮤니티 확장·학습/게임·공용 개발 환경·호스팅·개발 유틸리티는 이번 범위에 넣지 않는다.
- 2026-10월의 결정 기록은 당시 이력으로 보존한다. 현재 범위가 충돌하면 본 개정과 최신 명세를 따른다.

## 3. 요구사항 정합성을 위한 처리

- SSH의 무설치 조건은 그대로 유지하며 선택형 CLI 설치와 MCP 설정은 별도로 구분한다.
- 연동 자격·공통 권한·회수, 단발 요청과 지속 접속/집중 구간 구분을 추가한다. 복구·비밀번호 변경·탈퇴가 연동 자격에도 반영되도록 한다.
- 모집글은 기존 게시글의 특수 유형이다. 기존 댓글·신고·관리 삭제·보존 규칙을 적용하고 개인 저장은 비공개로 유지한다.
- 공개 GitHub 이슈와 사용자 작성 opensource 게시글을 분리한다. 외부 장애·AI 설명 실패·최신 상태 미확인을 각각 표시한다.
- 위의 세부 동작은 확정 기능을 일관되게 설명하기 위한 분석상 구체화이며 신규 제품 방향이나 구현 완료를 뜻하지 않는다.

## 4. 설계 전에 정할 항목

- 중·소규모의 규모 구간, 신생 기간, 트렌드 관찰 기간 및 선정 규칙. 임의의 수치를 확정된 수요 근거로 사용하지 않는다.
- GitHub 자료 갱신 주기와 외부 한도 대응, AI 제공자·모델·비용 한도.
- CLI 명령 규격, MCP 도구·전송 규격, 보호된 사용자 인증 방식, 연동 자격 만료 기간.
- 기존 성능 수치 제외 결정은 유지한다. 위 항목은 범위 확장이 아니라 상세 설계 사항이다.

## 5. 변경 확인 기준

1. 동일 계정으로 TUI·CLI·MCP에서 같은 게시글과 모집 상태를 조회한다.
2. CLI 비대화형 입력·구조화된 결과와 MCP 도구 입력/출력을 제공한다. 결과 없음과 실패를 구분한다.
3. 조회 전용 자격의 쓰기, 타인 글 수정, 회수·만료 자격 및 관리자 권한 회수 후 관리자 작업을 거부한다.
4. 복구·비밀번호 변경·탈퇴 시 연동 자격 무효화를 확인한다. 민감 입력을 모델이나 일반 로그에 노출하지 않는다.
5. 단발 요청은 접속·집중을 자동 생성하지 않는다. 지속 집중 세션 단절은 기존 집계 규칙을 따른다.
6. 재시도로 게시·마감·저장 등 같은 쓰기를 중복 적용하지 않는다.
7. 이슈 조건 탐색, 선정 근거·자료 시점, AI 근거 표시와 GitHub 원문 이동을 확인한다.
8. 닫힌/삭제 이슈, 외부 조회 한도, AI 실패를 정상 후보·빈 결과·완료 상태로 오인하지 않는다.
9. AI·외부 본문의 지시로 코드 실행·원클릭 준비·PR 작성이 발생하지 않는다.
10. 모집글 필수 조건·공개 안내·작성자 권한·마감·본인 저장·글 삭제/탈퇴 후 저장 정리를 확인한다.
11. FR↔UC 추적과 독립/본문 도식의 개념·관계를 일치시킨다.
12. 공유 ZIP의 각 파일이 최신 문서와 바이트 단위로 일치한다.
