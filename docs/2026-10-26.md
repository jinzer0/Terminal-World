# Terminal-World 요구사항 결정 기록

기록 기간: 2026-10-26~2026-10-27

## 1. 2026-10-26 서비스 범위와 계정 정책

분석 대상은 여러 사용자가 SSH로 접속하는 개발자 소셜 서비스로 정했다. 프로필·개인 공간·방명록과 목적별 공용 공간을 기본 기능으로, 외부 연동·이미지 표시·공유 터미널 기반 페어 프로그래밍을 확장 기능으로 분류했다.

| 결정 항목 | 결정 내용 | 명세 위치 |
|---|---|---|
| 가입·인증 | 서비스 내부 계정으로 가입·로그인하며 가입 시 개인 공간을 생성한다. 입력 형식과 로그인 실패 제한을 정했다. | 5.3절, FR-03~FR-05 |
| 콘텐츠 권한 | 게스트는 공개 정보를 조회하고 회원은 작성 활동에 참여한다. 작성자·공간 소유자·관리자의 수정·삭제 권한을 구분했다. | 4절 |
| 집중·접속 상태 | 목표 시간 없는 집중 추적과 일별 집계를 채택했다. 계정당 진행 구간 하나, 중복 로그인, 단절 처리, 자리 비움 상태 통합을 정했다. | 5.2절 |
| 계정 복구 | 아이디·복구 코드로 비밀번호를 재설정한다. 코드 발급·재발급·표시·저장·실패 제한을 정하고 이메일 복구·관리자 임의 초기화는 제외했다. | 5.4~5.5절 |
| 비밀번호 변경 | 현재 비밀번호를 재확인하고 변경한 세션 외의 세션을 종료한다. 복구 코드는 유지한다. | 5.6절 |
| 탈퇴 | 세션 종료, 개인 공간·집중 기록 삭제, 남은 작성물 표시, 개인정보 삭제 기한과 이름 재사용을 정했다. | 5.4절 |

## 2. 2026-10-27 후속 정책

| 결정 항목 | 결정 내용 | 명세 위치 |
|---|---|---|
| 공개·콘텐츠 관리 | 프로필·게시글·방명록의 공개 범위, Cafe 게시판 6개, 방명록 수정 권한과 삭제된 공간의 방명록 보관을 정했다. | 4절, FR-09~FR-10 |
| 관리자·신고 | 운영자의 관리자 지정·회수, 콘텐츠 삭제 기준, 신고 검토·중복 및 빈도 제한·결과 조회를 정했다. 개인 차단·계정 제재는 제외했다. | 4절, FR-24~FR-25 |
| 채팅·기록 보존 | 채팅 이력·재전송 처리와 신고·삭제 이력의 보존 기간을 정했다. | FR-13, 5절 기록 보존 |
| 백업·개인정보 | 백업 주기·보관·복구 후 삭제 재적용, 개인정보 삭제 요청과 운영 기록의 처리 기준을 정했다. | 5.7~5.9절 |
| 탐색·꾸미기 | 월드·목록 탐색, ASCII 아트 직접 입력·프리셋, 테마, 고정 레이아웃과 미리보기를 채택했다. | FR-06·FR-08 |
| 입력·지원 환경 | 프로필·콘텐츠 길이, 허용 문자·줄바꿈, 지원 터미널과 화면 크기를 정했다. | 5.10~5.13절 |

## 3. 초기 제안의 변경

| 초기 내용 | 후속 결정 |
|---|---|
| 목표 시간을 설정하는 타이머 | 목표 시간 없는 집중시간 추적으로 변경 |
| 비밀번호 15~128자·조합 강제 없음 또는 소문자·대문자·숫자 모두 필수 제안 | 10~24자·네 종류 중 최소 세 종류로 확정 |
| 신고 1분당 10건·3분당 10건 | 3분당 30건·마지막 성공 접수 후 3분 초기화로 변경 |
| 채팅 본문 장기 유지 | 전송 시각부터 14일 보존으로 확정 |
| 접속 상태 3초 반영·단절 30초 감지, 시험 환경표 | 2026-10-28 성능·품질 범위 조정으로 삭제 |
| 성능·RPO/RTO·일반 장애·잔여 품질 기준 검토 | 2026-10-28 제외 결정으로 종료 |

세부 정책은 [요구사항 분석 명세](requirements-analysis.md), 최종 변경은 [10월 27~28일 기록](2026-10-27.md)에 정리했다.
