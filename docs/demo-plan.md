## 1. 완료 기준

기능 요구사항 30개(FR-01~FR-20, FR-22~FR-31)와 UC-01~UC-18을 아래 시연 항목으로 확인한다. 삭제된 FR-21은 복원하지 않는다. 표의 FR 연결은 유스케이스별 추적이며, 각 기능의 세부 동작·입력·권한·보존 기준은 원본 명세를 적용한다.

1. 서로 다른 두 회원과 게스트·관리자가 같은 서버 데이터를 이용한다. 화면 예시 사용자나 한 프로세스의 가짜 대화로 다중 사용자를 대신하지 않는다.
2. SSH TUI·업무 CLI·MCP에서 동일한 업무를 실행한다. 월드 애니메이션·키 입력·미리보기의 CLI/MCP 표현은 요구사항 5.15절을 따른다.
3. 가입·저장·조회·수정·삭제·재접속·서버 재시작 후 결과가 일관된다. 성공은 저장 확인 후 표시한다.
4. 비로그인 쓰기·타인 자료 변경·만료/회수 자격·관리자 권한 회수 후 작업을 거부한다. 복구·비밀번호 변경·탈퇴가 기존 세션과 연동에 반영된다.
5. 채팅·접속·집중 기록은 실제 연결과 서버 시간을 기준으로 작동한다. 단발 CLI/MCP 호출은 온라인 상태나 집중시간을 만들지 않는다.
6. GitHub 공개 조회의 외부 장애·빈 결과·오래된 자료·결과 미확인을 구분한다. 인기 저장소를 실제 공개 자료로 표시하고 마지막 확인 시점을 함께 제공한다. AI 설명은 외부 호출 없는 데모 응답임을 화면·CLI·MCP 결과에 명시한다. FR-30의 실제 모델 생성·품질 검증은 이번 데모 완료 범위에 포함하지 않는다.
7. 기능 테스트와 실제 터미널 시연, MCP 프로토콜 클라이언트의 도구 발견·호출을 확인한다. 외부 AI 모델을 호출하지 않고도 MCP 전송·입출력·권한을 검증한다. 자동 테스트만으로 화면 배치·키 조작·실제 AI 호스트 연동 완료를 판정하지 않는다.
8. NFR-06의 환경·화면·한글/이모지 호환성을 점검한다. macOS에서만 확인한 결과를 Linux·Windows 검증으로 확대하지 않는다.

보류·제외 범위는 2026-11-02 결정대로 유지한다. 서비스 공개 배포나 외부 비용 지출은 데모 구현과 별도다.

## 2. 시작 시점의 구현 상태

| 항목 | 확인한 현재 코드 | 남은 작업 |
|---|---|---|
| 진입·화면 | `src/cli.tsx`, `src/App.tsx`의 로컬 Ink TUI | SSH 접속, 게스트/회원 인증, 전체 공간·화면 연결 |
| 개인 공간 | `src/model.ts`의 `user:local`, 예시 사용자 방문, 프로필 편집 | 실제 계정별 공간, 최신 프로필·ASCII·테마 규칙, 공유 조회 |
| 채팅·방명록 | 로컬 이력과 고정 예시 데이터 | 실제 사용자 송수신, 권한별 수정/삭제, 보존·중복 방지 |
| 저장 | `src/storage.ts`의 사용자 디렉터리 JSON·단일 작성자 잠금 | 서버 저장소, 계정/세션/권한 검증, 트랜잭션과 복구 |
| CLI | `--help`, `--version`, `--no-mouse`, TTY 실행 | 업무 명령, JSON 출력, 실패 상태, 페이지 정보, 지속 구독 |
| 나머지 | 대응하는 업무 구현 확인 안 됨 | Cafe·공지·접속·집중·자리 비움·관리·모집·MCP·이슈/AI |

기존 로컬 UI·입력·저장 코드는 재사용 후보이며, 최신 요구사항을 이미 충족한다고 판정하지 않는다. 기존 사용자 상태 파일을 새 서버 데이터로 자동 덮어쓰거나 초기화하지 않는다.

## 3. 진행 순서

| 단계 | 작업 | 단계 완료 증거 |
|---|---|---|
| 1 | 전체 데모 범위·시연 기준·구현 현황 정리 | 본 계획의 FR/UC 누락 확인, 기존 검사 결과 확보 |
| 2 | 공통 서버·데이터·인증·권한 구조 설계 | 구성도, 저장·트랜잭션 경계, 주요 흐름, CLI/MCP 인증 경로, 첫 구현 단위 확정 |
| 3 | 공통 기반과 가입·로그인·개인 공간 생성 | 두 회원의 분리된 계정/공간, 동시 가입 중복 방지, 로그인 제한, 저장 후 재시작 복원 |
| 4 | SSH TUI·게스트 탐색·월드/목록·프로필·방명록 | 실제 SSH 접속, 최소 화면 목록, 공개 방문·소유권 검사, 최신 입력 규칙 |
| 5 | 게시판·댓글·공지·모집 | 공개 조회와 본인 편집, 모집 검색·마감·개인 저장, 원글/댓글 삭제 규칙 |
| 6 | 접속·실시간 채팅·집중·자리 비움 | 두 연결 간 전파, 중복 전송 방지, 집중 단절·다중 세션·한국 시간 자정·공동 순위 |
| 7 | 계정 복구·변경·탈퇴·신고·관리·보존 | 기존 자격 무효화, 관리자 회수, 신고 제한, 탈퇴 익명화·보존, 백업 복구 후 삭제 재적용 |
| 8 | 업무 CLI·MCP 전체 기능 연결 | 기존 공통 업무 호출, 업무별 허용 범위, 민감 입력 보호, 지속 구독, 외부 AI 호출 없는 MCP 프로토콜 검증 |
| 9 | 공개 GitHub 저장소·이슈 탐색·AI 데모 설명 | 계정 연결 없는 인기 목록·이슈 조회, 선정 근거·자료 시점·원문 연결, 한도·오래된 자료, 데모 설명/설명 없음 표시 |
| 10 | 전체 시연·호환성·패키징 | 아래 UC 전체 시연, 단위/통합 검사, 실제 터미널/MCP 클라이언트 확인, 재현 가능한 실행 안내 |

CLI/MCP 입력·출력과 권한 요구는 2단계부터 설계한다. 8단계에서는 이미 구현한 공통 업무를 어댑터에 연결하며 별도 업무 로직을 복제하지 않는다. 각 단계에서 해당 기능의 테스트를 작성·실행하고, 10단계에서 전체 연결을 확인한다.

## 5. 정책과 기술 선택 확정 요약 (2026-11-28)

- **아키텍처(2단계 확정)**: 초안 C(모듈형 모놀리스 + 2단계 어댑터형) — `src/core/` 순수 도메인 코어 + 내장 `node:sqlite`(WAL/마이그레이션/Tombstone) + 내장 `ssh2` TUI + 로컬 HTTP/SSE 브릿지 + CLI + 전송 분리 MCP(`stdio` 기본, `--mcp-http` 선택). 추가 의존성은 `ssh2`, `@modelcontextprotocol/sdk`, `zod` 3종([architecture-spec.md](architecture-spec.md)).
- **인증·연동 자격(2단계 확정)**: 브라우저 비의존 SSH/CLI 6자리 원타임 승인 코드(5분), 일반 승인 최대 **30일**(기본 7일), 관리자 범위 **4시간**, **Access(1h/관리자 30m) + 일회용 Refresh(7d/관리자 1h) 로테이션** 및 Replay 탐지 시 Grant 전체 회수([architecture-spec.md](architecture-spec.md), [interface-spec.md](interface-spec.md)).
- **2.5D 월드 UI(2단계 확정)**: `120×30` 이상 **아바타 자유 이동 2.5D 맵**(확대/축소 없이 카메라 패닝) + `m` 토글 목록 탐색(`80×24~119×29` 자동 기본)([interface-spec.md](interface-spec.md)).
- **오픈소스 선정(확정)**: 스타 인지도 구간(소규모 0~999·중규모 1,000~9,999), 신생 기준 **1년(365일) 미만**(Q-03), 트렌드 관찰 창 **7일 스타 순증**(미관측 시 `미분류`). 공개 인기 저장소 목록과 기여 이슈 탐색은 분리하며, 비인증 REST + Singleflight 캐시 + 시드 스냅샷을 사용한다.
- **AI 데모 설명**: 외부 모델·API 키·유료 호출 없이 준비된 데모 응답을 사용한다. `mode: 'demo'`, `demoAuthoredAt`, `sourceCheckedAt`를 명시하고 불일치/부재 시 설명 없음으로 처리한다.
- **보존·백업 검증**: 일/14일/90일 보존·7일 백업 복구 후 삭제 재적용은 주입 가능한 `Clock`과 격리된 테스트 데이터로 검증한다. 실제 보존 기간을 시연 편의에 맞춰 줄이지 않는다.

## 6. 검증 기록

2026-11-08, 변경 전 기존 로컬 프로토타입:

- `npm test`: 55개 통과, 실패·건너뜀 0.
- `npm run typecheck`: 통과.
- `npm run build`: 통과.
- 별도 `lint` 스크립트는 없다. 패키지 설치/배포 매트릭스인 `test:package`는 이번 문서 작업에서 실행하지 않았다.
- GitHub 공개 조회 예비 확인: 2026-11-08, 인증 헤더 없이 `GET /search/repositories`를 요청해 HTTP 200·결과 3개·`incomplete_results=false`를 확인했다. 질의는 TypeScript·1,000스타 이상·MIT·보관/포크 제외·누적 스타 내림차순이다. 이는 방법의 실행 가능성 확인이며 제품에 인기 목록·캐시가 구현됐다는 뜻은 아니다.
- SSH·서버·MCP·지원 OS 전체 시연은 아직 검증하지 않았다. 실제 AI 모델 연결은 이번 데모에서 수행하지 않는다.
