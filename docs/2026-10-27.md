- [이전 결정 기록](2026-10-26.md): 계정·콘텐츠·운영·탐색 정책의 결정 과정

## 2. 2026-10-27 정책 확정

P-01~P-07·P-09~P-11의 계정·콘텐츠·운영·입력·지원 환경 정책을 확정했다. 결정 내용은 [이전 기록](2026-10-26.md), 세부 기준은 [요구사항 분석 명세](requirements-analysis.md)에 정리했다.

## 3. 2026-10-28 범위 조정

| 항목 | 최종 결정 |
|---|---|
| 브라우저 비의존(CON-02) | 가입·로그인·프로필·게시판·채팅 등 기본 기능을 SSH 터미널에서 이용한다. 외부 프로젝트 URL 표시는 유지한다. |
| 성능(P-08) | 응답 시간·동시 접속 규모·부하·시험 데이터 규모·측정 조건·성능 시험과 인수 기준을 제외한다. 접속 상태 반영·단절 감지의 시간 상한도 삭제한다. |
| RPO·RTO | 요구사항·인수 기준에서 제외한다. 백업 주기·보관·접근 권한과 복구 후 삭제 재적용은 유지한다. |
| 일반 장애·공통 규칙 | FR-21, BR-02·BR-04·BR-05와 관련 인수 기준·공통 오류 처리 제안을 삭제한다. |
| 비기능 요구사항 | NFR-01~NFR-05·NFR-07~NFR-08을 삭제하고 NFR-06 호환성은 유지한다. |
| 시험 환경표 | OS·SSH·터미널 버전·글꼴 등 시험 재현 조건을 고정하는 요구사항을 삭제한다. 지원 환경 자체는 유지한다. |
| 공지 | ‘관리자 탈퇴 후 공지 처리’ 추가 정책·검토 항목을 삭제한다. 기존 공지 기능과 Notice 관계는 유지한다. |

기능별 권한·인증·입력·채팅·보존·백업 정책은 유지한다. 삭제한 식별자는 재사용하지 않는다.

## 4. 2026-10-28 모델 수정 및 문서 검사

- 게스트의 공개 방명록 조회를 UC-05와 참여 도식에 반영했다.
- 개인 공간 속성에서 `welcomeText`를 제거하고 프로젝트 URL·확정 정책의 상태 표기를 수정했다.
- 유스케이스·도메인 도식을 Mermaid·PlantUML로 각각 작성하고 다음 항목을 검사했다.

| 요구사항·유스케이스 | FR 24개·NFR 1개·UC 14개 집계, FR↔UC 연결, 상세 명세 필수 항목 확인 |
| 유스케이스 도식 | 두 형식의 액터 3개·UC 14개·참여 관계 27개와 관리자 역할 관계 대조 |

| 문서 구조 | 로컬 링크·제목 앵커·코드 블록 확인 |
