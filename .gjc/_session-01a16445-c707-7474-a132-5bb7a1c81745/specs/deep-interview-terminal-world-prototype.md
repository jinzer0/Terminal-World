## Goal
Terminal World는 macOS에서 로컬로 실행하는 목록형 다크 TUI 커뮤니티 프로토타입으로, 닉네임으로 입장해 키보드와 마우스로 로비·채팅·예시 사용자의 개인 터미널을 오가고, 내 소개·상태·ASCII 프리셋·개인 영역 테마를 꾸미며, 프로필과 직접 작성한 채팅·방명록을 재실행 후에도 유지하는 자기표현 경험을 제공한다.

핵심 가치는 ‘월드 안에 나만의 공간이 생겼다’는 자기표현이다. 실제 다중 사용자 서비스를 구축하는 단계가 아니다.

## Constraints
- 실제 터미널에서 실행하는 TUI이며 웹 화면 모사가 아니다.
- 현재 단계는 macOS 로컬 프로토타입이다. 네트워크 서비스나 SSH 서버를 요구하지 않는다.
- 처음에는 닉네임을 정해 들어간다. 저장된 프로필이 있으면 재실행 후 유지한다. 이 두 동작은 R16에서 함께 확인했다.
- 개인 터미널의 편집 대상은 소개·상태·ASCII 프리셋·테마다. 닉네임은 진입 시 정하고 저장한다. 닉네임 변경 기능 자체는 필수로 확정하지 않았다.
- 레이아웃은 고정한다. 개인 콘텐츠와 테마를 바꿀 수 있으나 창/패널 배치를 편집하는 도구는 만들지 않는다.
- 예시 사용자는 시연 데이터다. 로비에서 다른 사용자가 보이더라도 실제 접속 상태나 실제 원격 사용자로 표현하지 않아야 한다.
- 로컬 메시지와 방명록은 실제 상대에게 전달되지 않으며 상대 반응을 자동 생성하지 않는다.
- 기본 키: 방향키로 목록 이동, Tab으로 목록/내용 사이 포커스 전환, Enter로 열기/선택, Esc로 뒤로가기/편집 취소, Ctrl+C로 종료.
- 입력 영역에 포커스가 있으면 일반 문자를 그대로 입력할 수 있어야 한다. 저장·전송 방법을 화면에 표시한다.
- 마우스 클릭과 스크롤을 지원한다. 구체적인 클릭 대상과 이벤트 처리는 계획에서 검증 가능한 동작으로 명세한다.
- 개인 터미널 테마는 그 소유자의 콘텐츠 영역에만 적용한다. 방문자는 방문한 사용자의 테마를 본다.
- 예시 사용자 데이터와 사용자가 만든 로컬 데이터의 구분을 유지한다.

- 가상 사용자의 자동 답장 및 원격 방명록 전달.
- Cafe 게시판과 Focus Room 집중 타이머.
- 격자형 터미널 창 지도, 카메라 확대/축소, 캐릭터 이동 방식.
- 패널 배치 편집기, ASCII 직접 작성/붙여넣기 편집기.
- CRT 빛 번짐이나 화면 휘어짐을 재현하는 효과.
- 원안의 협업 공간, tmux 페어 프로그래밍, 일정, 코드 스니펫, GitHub 연동.
- 이번 단계의 Linux/Windows 호환 보장. 최종 서비스에서 지원하지 않는다는 뜻은 아니다.

## Acceptance Criteria
사용자가 R16에서 확인한 완료 기준이다.

- [ ] **AC1 — 진입:** macOS에서 로컬 실행 후 처음에는 닉네임을 정해 입장하고 그 이름이 내 개인 터미널과 작성한 내용에 사용된다. 저장된 프로필은 재실행 후 유지된다.
- [ ] **AC2 — 탐색:** 현대적인 다크 TUI의 왼쪽 목록에서 로비·RoofTop·내 터미널·예시 사용자의 터미널을 선택하면 오른쪽에 대응하는 내용이 표시된다.
- [ ] **AC3 — 꾸미기:** 내 소개·상태·ASCII 프리셋·테마를 변경할 수 있다. 방문한 다른 사용자의 터미널은 그 사용자의 콘텐츠와 테마로 표시된다. 개인 테마 변경이 공용 화면과 왼쪽 목록의 기본 다크 스타일을 바꾸지 않는다.
- [ ] **AC4 — 공용 공간:** 로비에서 예시 사용자들을 확인하고 개인 터미널로 진입할 수 있다. RoofTop에서 직접 입력한 메시지가 내 작성자 표시와 함께 화면에 추가된다. 원격 사용자나 자동 응답은 필요하지 않다.
- [ ] **AC5 — 방명록:** 예시 사용자의 개인 터미널에 짧은 글을 남기고 해당 대상의 방명록에서 확인할 수 있다. 다른 터미널의 방명록과 혼동되지 않으며 원격 전달이나 자동 답장은 없다.
- [ ] **AC6 — 조작:** 기본 키와 마우스 클릭·스크롤로 목록과 콘텐츠를 조작할 수 있다. 입력 중에는 일반 문자가 입력되며 화면에서 저장/전송 방법을 확인할 수 있다. Esc의 취소 동작과 Ctrl+C 종료가 작동한다.
- [ ] **AC7 — 재실행:** 프로필·직접 보낸 채팅·대상별 방명록을 작성한 뒤 앱을 종료하고 다시 실행해 같은 로컬 데이터가 유지되는지 확인한다.
- [ ] **AC8 — 범위 준수:** 위 Non-Goals를 구현에 몰래 추가하지 않는다. 실제 통신이 없는 부분을 동작하는 실서비스처럼 주장하지 않는다.

권장 시연 순서: 첫 진입 → 내 공간 꾸미기 → 예시 사용자 방문 및 테마 비교 → 방명록 작성 → RoofTop 메시지 작성 → 종료/재실행 → 저장된 내용 확인. 이 시나리오는 구현 검증용이며 아직 실행하지 않았다.

## Technical Context
- 검토한 사용자 자료: `세부기능.md`, `main.png`, `profile.png`.
- 기능 문서는 SSH·격자 공간·여러 공용 활동·개인 터미널·협업 확장을 제안한다. 이미지는 녹색 터미널과 여러 프로필 패널을 묘사한다.
- 참고 자료 전체가 구현 의무는 아니다. 현재 인터뷰에서 확정된 결정이 이번 프로토타입 범위를 정한다.
- 초기 루트 조사에서 앱 소스 및 package.json/go.mod/Cargo.toml은 발견되지 않았다. `_bmad` 등은 워크플로 자료다. 신규 제품 설계로 취급했다.
- 기술 스택은 아직 선택하지 않았다. 이번 인터뷰에서 소스 작성·테스트·빌드·제품 구현을 수행하지 않았다.
- 현재 저장소의 브랜치는 앞선 사용자 요청에 따라 main으로 설정했다. Git 조작은 이번 인터뷰의 구현 승인을 뜻하지 않는다.
