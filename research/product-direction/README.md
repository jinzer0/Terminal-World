# Terminal World 제품 방향 리서치

`index.html`을 브라우저에서 열면 실행됩니다. 인터넷 연결이나 설치, 빌드가 필요하지 않습니다. 외부 출처 링크를 열 때만 인터넷을 사용합니다.

조사 기준일: 2026-10-29 (Asia/Seoul). 공식 문서 접근은 실제 계정 가입·SSH 접속·결제 테스트와 구분했습니다. 점수는 시장 통계가 아니라 공개 근거를 토대로 한 비교 판단입니다.

24개 서비스·도구, 10개 후보, 9개 평가 기준, 63개 출처 항목(62개 고유 URL)을 담았습니다. 12개 보고서 항목과 최종 5개 질문의 답을 HTML에 통합했습니다.

기존 프로젝트 코드, 문서, 발표용 루트 `index.html`은 보존했습니다. 리포트의 시뮬레이션은 실제 제품 구현이나 사용자 실험 결과가 아닙니다.

원본 구성: `shell.html`, `sections-a/b/c.html`, `style.css`, `app.js`, 조사 JSON. 수정 후 `python3 build.py`를 실행하면 하나의 독립적인 `index.html`로 묶습니다. 평소 열람에는 이 과정이 필요하지 않습니다. 생성된 HTML만 복사해도 탐색 기능이 작동하며, 저장소 코드 참조 링크는 원래 폴더 위치에서 사용합니다.

`verification.json`에 검수 범위와 한계를 기록했습니다. `qa/`에는 데스크톱·모바일·두 테마의 검수 화면 및 인쇄 확인 결과가 있습니다. 내장 브라우저의 파일 주소 제한으로 실제 UI 검수는 로컬 HTTP 미리보기에서 수행했고, 외부 요청 없는 로딩과 네트워크 차단 상태의 인터랙션을 확인했습니다.
