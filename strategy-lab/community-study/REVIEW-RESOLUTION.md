# 독립 검수 지적 사항 처리

통합 담당자 최종 확인: 2026-10-30. `evidence-audit.md`와 `final-content-audit.md`는 검수 당시의 판단을 그대로 보존한다. 이 문서는 이후 수정과 확인 내용을 기록하며 독립 검수자가 다시 승인했다는 뜻이 아니다.

| 지적 | 반영 및 확인 |
|---|---|
| NaNoWriMo 종료의 독립 교차 확인 과장 | 원 조직 종료와 후속 활동을 구분했다. NaNo2FAQ의 설명, 원 공지 접근 한계, 전 지역 운영자의 이탈·운영 부담 회고를 구분하고 회고를 종료의 독립 확인으로 쓰지 않았다. 사례와 심층 기록 모두 수정했다. |
| Yesterweb 근거 유형 | 운영자 회고이므로 `official`로 수정했다. 일반 참여자 후기처럼 세지 않는다. |
| Discord·VRChat 후기의 날짜 | 원문에서 확정할 수 없는 정확한 날짜를 사례와 심층 기록에서 제거했다. |
| 미래 행사·게시 빈도 표현 | Codeforces 2026-10-31 행사는 예정으로 표시하고 Recurse 소개는 평일 정기 공개로 좁혔다. |
| tilde.town의 보안 위험 | 예방 규칙을 실제 침해 사고 관측처럼 설명하지 않도록 수정했다. |
| 비교 실험과 파일럿의 일정 충돌 | W1 인터뷰 → W2 수동 프로토타입으로 기존 도구 비교 → W3–4 MVP → W5–6 14일 자유 이용 → W7–8 개선·시연으로 데이터와 보고서를 통일했다. 모든 실험은 향후 계획이다. |
| 설치 없는 진입의 단정 | 클라이언트 진입 후 작품마다 추가 런타임을 설치하지 않는 설계 목표로 좁혔다. 최초 설치·접속 비용과 SSH 경로는 검증 대상으로 남겼다. |
| 출처 개수의 범위 | 사례의 151개에 심층 분석의 추가 URL을 합친 고유 URL 153개로 통일했다. 접근 실패 후보 4개는 별도다. |
| 심층 출처의 스키마·노출 | 문자열 URL을 원래 출처 메타데이터 객체로 정규화했다. HTML 심층 영역에도 별도 출처를 표시하고 보고서에도 추가 URL을 포함했다. |

재생성 후 사례 83건·심층 29건·아이디어 9개의 수량, 출처 참조와 보고서 URL 153개 포함 여부를 확인했다. HTML 내장 원문과 별도 보고서도 일치한다. 브라우저 40개 검사는 모두 통과했으며 상세 범위와 한계는 `../QA.md`에 있다.

## 남겨 둔 제품 반론

공동 제작의 선행 사례가 있다는 사실은 Terminal World의 수요나 독립 서비스의 필요성을 증명하지 않는다. 제한된 작품 형식이 재미를 줄이고, 기여 검토가 운영 병목이 되며, 터미널 진입이 참여를 막을 수 있다. 시드 작품 공급과 인간의 응답에도 비용이 든다. 기존 Discord/GitHub로 동일 활동의 가치가 충분하면 별도 제품 개발을 중단한다. 참여자 간 실행·변형·반응이 이어지지 않으면 혼자 작품을 보는 기능만으로 커뮤니티 가설을 통과시키지 않는다.
