검증일: 2026-10-30 (KST). 대상: `index.html`, `research-report.md`. 이전 Checkpoint 버전의 기록은 `archive/checkpoint-2026-10-29/`에 보존했다.

## 콘텐츠와 출처 정합성

- 등록 후보 87건 중 분석 사례 83건, 접근 실패 후보 4건을 구분했다. 공동체·플랫폼·네트워크·행사·종료 사례를 포함한다. 웹 전체의 완전한 전수 조사 또는 현재 활성 공동체 83곳을 의미하지 않는다.
- 심층 분석 29건, 아이디어 9개, 상위 후보 3개를 확인했다. 모든 사례 이름과 사례·심층 분석의 고유 출처 URL 153개가 보고서에 포함된다. 모든 URL의 현재 본문 접근 성공을 뜻하지 않는다.
- 전체 보고서 120,205자와 HTML에 포함된 다운로드 원문이 일치한다. 외부 데이터 파일 없이 핵심 콘텐츠와 상세 보고서에 접근할 수 있다.
- 가중치 합은 100이다. 기본 점수는 공동 제작 터미널 마을 74, Commons Lab 68, 실제 사용 리뷰 교환 클럽 65다. 점수·수요·우위·실험 문턱은 가설이며 성공 확률이나 사용자 실험 결과가 아니다.
- 독립 검수에서 지적한 일정 불일치, 설치 부담의 단정, 출처 유형과 종료 근거의 과장을 수정했다. 수정 내역은 `community-study/REVIEW-RESOLUTION.md`에 기록했다.

## 브라우저 검증

실제 Chrome을 Playwright로 실행했다. `community-study/verify.mjs`의 **40개 검사 전부 통과**. 상세 결과는 `community-study/qa/results.json`에 보존했다.

- HTML만 별도 위치에 복사하고 네트워크를 차단한 `file://` 환경에서 검사했다. JavaScript 오류 0건, 외부 HTTP 리소스 요청 0건이었다.
- 11개 섹션, 사례 83건의 페이지 이동·검색·분야 필터·근거 필터·심층 펼치기·빈 결과 표시를 확인했다.
- A/B/C별 아이디어 3개씩, 최대 3개 비교와 초기화, 상위 후보 전환과 키보드 화살표 이동을 확인했다.
- 기본 점수, 가중치 재계산, 공동 1위, 모든 가중치가 0인 경우와 초기화를 확인했다.
- 다크 기본값, 라이트 전환, 새로고침 후 테마 유지, 모바일 메뉴와 Escape 닫기를 확인했다.
- 가상 제품 예시의 상태 변화·초기화, 내장 보고서 다운로드와 원본의 바이트 일치를 확인했다.
- 320·375·768·1024·1440px의 두 테마에서 상세 내용을 펼친 상태로 페이지 가로 넘침이 없었다. 내부 링크와 출처 링크의 누락·잘못된 앵커도 검사했다.

`community-study/visual-check.mjs`로 핵심 글자/배경 CSS 색상 조합 36쌍을 검사했다. 모두 4.5:1 이상이고 최소값은 5.52:1이다. 결과는 `community-study/qa/contrast.json`에 있다. 모든 시각 상태의 접근성 인증을 의미하지 않는다.

데스크톱 Hero·Idea Explorer·Decision Lab 및 모바일 Hero·아이디어·평가 화면을 이미지로 직접 확인했다. 캡처는 `community-study/qa/`에 있다. 화면 크기 변경 직후 캡처의 헤더 잔상은 렌더링 프레임을 기다린 뒤 재촬영해 해소했으며 제품 코드를 변경할 필요는 없었다.

## 한계와 보존

실제 모바일 기기, Safari·Firefox, 스크린리더는 검증하지 않았다. 외부 출처 열람은 인터넷과 해당 사이트의 접근 허용이 필요하다. 공개 자료 조사는 인터뷰·모집·재방문 실험을 대신하지 않는다. 제품 예시는 브라우저 내부의 가상 시연이며, 실제 공동 제작 서비스나 원격 실행 서버를 구현한 결과가 아니다.

기존 앱·발표 자료는 수정하지 않았다. `strategy-research/originals.sha256`으로 루트 `index.html`, `src/cli.tsx`, `src/App.tsx`, `src/storage.ts`, `package.json`의 보존을 다시 확인했다.

## 재현과 기록 위치

빌드는 `community-study/assemble-data.py` → `community-study/build-report.py` → `build.mjs` 순서로 실행한다. 각 단계 성공 후 다음 단계로 진행한다. 브라우저 검사 스크립트의 Playwright/Chrome 경로는 이 작업 환경의 경로다.

이번 버전의 검증 원장은 이 문서와 `community-study/qa/`이다. 상위 폴더의 이전 `qa-results.json`, `qa-probe.json`, `contrast-check.json` 등은 이전 버전의 기록이므로 이번 결과로 해석하지 않는다.
