# 검증 기록

대상: `index.html` / `research-report.md` · 기준일: 2026-10-29

## 콘텐츠 검수

- 경쟁 제품 16개, 타깃 7개, 아이디어 9개, Mini PRD 3개, 공통 출처 28개를 확인했다.
- 모든 출처 ID 참조가 유효하고 보고서에 해당 URL이 포함되어 있다.
- 기본 가중치 합은 100, 점수는 Checkpoint 75 / Unblock Desk 71 / Study Dock 65다.
- 구현 가능성의 가중치를 0으로 내리면 앞의 두 후보가 72.22점으로 동률이다.
- 점수·가중치·사용자 페르소나·실험 문턱은 분석 가설이다. 사용자 인터뷰·제품 사용 실험은 수행하지 않았다.
- Gather는 최종 검수에서 최신 공식 1.0/2.0 비교로 보완했다.
- 기존 앱 구현 판단은 소스 정적 확인이며, 이번 작업에서 기존 TUI 전체를 실행 검증하지 않았다.

## 링크 검사

`link-check.json`에 28개 외부 URL의 직접 HTTP 확인 결과를 기록했다. 19개는 2xx 응답이고 9개는 자동 요청에 403을 반환했다. 404는 관측하지 않았다. 403 자료는 별도의 웹 연구에서 읽었으나, 모든 이용 환경에서 링크가 열린다고 보증하지 않는다. 오프라인 상태에서 외부 출처를 여는 기능은 인터넷 연결이 필요하다.

## 브라우저 검사

Chrome 156.0.8078.74에서 실제 브라우저를 실행해 18개 검증 그룹을 모두 통과했다. 상세 결과는 `qa-results.json`, 화면 너비별 결과는 `qa-probe.json`, 캡처는 `qa/`에 보존했다.

- `file://`에서 네트워크를 차단하고 콘텐츠와 전체 인터랙션을 확인했다. 외부 리소스 요청과 JavaScript 실행 오류는 0건이었다.
- 화면 너비 320·375·767·768·1023·1024·1440px에서 페이지 가로 넘침이 없었다. 320px에서 모든 상세 내용을 펼친 경우도 확인했다. 넓은 표는 자체 영역 안에서 스크롤된다.
- 두 테마 전환과 새로고침 후 선택 유지, 저장소 접근이 차단된 환경의 기본 동작을 확인했다.
- 경쟁 제품 필터, 사용자군 전환, 9개 아이디어 상세·필터·최대 3개 비교, 상위 3개 후보 탭, 사용자 흐름의 각 단계를 확인했다.
- 점수의 기본값·정규화·동률·추천 순위 변경·가중치 전체 0·초기화를 확인했다. 모바일에서는 슬라이더를 조정할 때 점수 요약을 함께 볼 수 있다.
- 키보드 상세 펼치기, 탭 화살표 이동, 모바일 메뉴 초점과 Escape, 읽기 진행 표시, 현재 섹션 강조, 움직임 감소 설정을 확인했다.
- 터치를 모방한 브라우저 환경에서 메뉴·필터·테마·슬라이더 조작을 확인했다.
- 내부 링크·중복 ID·조작 요소 이름을 검사했다. 두 테마에서 렌더링된 텍스트의 색 대비 표본은 WCAG AA 비율을 만족했다(`contrast-check.json`). 완전한 접근성 인증을 의미하지 않는다.
- 데스크톱과 모바일의 주요 섹션 및 두 테마 캡처를 직접 검토했다.

검증 한계: 화면 너비와 터치 입력은 데스크톱 브라우저에서 모방했다. 실제 모바일 기기, Safari·Firefox, 스크린리더는 검증하지 않았다. 이 웹사이트는 전략 탐색 도구이며 제안된 Checkpoint 제품 자체나 사용자 실험을 구현·수행한 결과가 아니다.
